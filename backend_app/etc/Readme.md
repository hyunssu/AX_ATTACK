# 📚 신규 단어 등록

> 새로운 용어를 등록하고 DB에 저장하는 기능입니다.

---

## 📌 접근 방법

### 방법 1. URL 직접 접근

`접속 도메인/term-test`

### 방법 2. ASK AI 메뉴에서 접근

**ASK AI 메뉴 → 왼쪽 사이드바 → `+ 신규단어 등록`**

---

## 🔄 등록 흐름

```text
┌─────────────────────────────┐
│      ASK AI 메뉴            │
│       왼쪽 사이드바         │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│      + 신규단어 등록         │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│      등록하시겠습니까?       │
└──────────────┬──────────────┘
               │ 예
               ▼
┌─────────────────────────────┐
│ 신규단어 / 동의어 / 카테고리 │
│          / 설명 입력         │
└──────────────┬──────────────┘
               │ 저장
               ▼
┌─────────────────────────────┐
│  TermManager.handleSubmit() │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│ POST /api/terms/register    │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│      FastAPI router.py      │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│         create_term()       │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│       INSERT INTO TERMS     │
└──────────────┬──────────────┘
               │
               ▼
        ✅ DB 저장 완료
```

---

## 📝 입력 항목

| 항목       | 필수 여부 | 설명            |
| -------- | :---: | ------------- |
| 신규단어     |   ✅   | 등록할 용어        |
| 동의어 및 약어 |   ❌   | 용어의 동의어 또는 약어 |
| 카테고리     |   ❌   | 용어의 분류        |
| 설명       |   ✅   | 용어에 대한 상세 설명  |
