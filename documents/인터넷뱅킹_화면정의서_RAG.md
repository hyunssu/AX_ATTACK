## [IB-TR-001] 계좌이체 (일반이체)

### 업무 설명

고객이 본인의 계좌에서 타행 또는 당행의 수취 계좌로 즉시 자금을 이체하는 화면입니다.
이체 실행 전 보안 인증(OTP, 인증서, 간편 비밀번호 등)을 거치며, 이체 한도 내에서 거래가 처리됩니다.
이체 완료 후 이체 확인증을 제공하며, SMS/앱푸시 알림 발송이 연동됩니다.

### 화면 구성 요소

- **출금 계좌 선택 영역** : 로그인한 고객의 보유 계좌 목록을 드롭다운으로 표시하며, 잔액 실시간 조회 가능
- **수취 계좌 입력 영역** : 은행 선택(당행/타행), 계좌번호 입력, 예금주 조회 버튼
- **이체 금액 입력 영역** : 금액 직접 입력, 빠른 금액 선택 버튼 (1만, 5만, 10만, 50만, 100만), 전액이체 버튼
- **이체 정보 요약 영역** : 입력된 출금 계좌, 수취 계좌, 이체 금액, 수수료, 최종 출금액 표시
- **받는 분께 전할 말 입력 영역** : 이체 메모 (수취인 통장 인자 내용)
- **보안 인증 영역** : 인증 수단 선택 및 입력 (OTP/인증서/간편비밀번호)
- **이체 실행 버튼** 및 **취소 버튼**
- **자주 쓰는 계좌 영역** : 즐겨찾기 등록된 수취 계좌 목록 (선택 시 자동 입력)

### 필드 정보

| 출금 계좌 잔액 | withdrawalBalance | Number | - | 표시용 | 선택된 출금 계좌 현재 잔액 | 읽기 전용 (시스템 조회) |
| 수취 은행 코드 | receiveBankCode | String | Y | 3자리 숫자 | 수취 은행 기관 코드 | 금융기관 코드 목록에서 선택 |

## [IB-TR-002] 예약이체

### 업무 설명

고객이 지정한 미래 날짜에 자동으로 이체가 실행되도록 예약하는 화면입니다.
예약 등록 시 이체 금액이 즉시 출금되지 않으며, 예약 실행일 당일 잔액 확인 후 이체가 처리됩니다.
예약 등록 후 예약 번호가 발급되며, 예약이체 목록에서 조회 및 취소가 가능합니다.

### 화면 구성 요소

- **출금 계좌 선택 영역** : 보유 계좌 드롭다운
- **수취 계좌 입력 영역** : 은행 선택, 계좌번호, 예금주 조회
- **이체 금액 입력 영역**
- **예약 실행일 선택 영역** : 달력 선택 UI (오늘 이후 날짜만 선택 가능, 최대 1년 이내)
- **예약 정보 요약 영역** : 입력 내용 전체 요약 표시
- **받는 분께 전할 말 입력 영역**
- **보안 인증 영역**
- **예약 등록 버튼** 및 **취소 버튼**
- **예약이체 목록 바로가기 링크**

### 필드 정보

| 출금 계좌번호 | withdrawalAcctNo | String | Y | 최대 20자리 | 이체 출금 계좌번호 | 본인 계좌 여부, 입출금 가능 계좌만 허용 |
| 수취 은행 코드 | receiveBankCode | String | Y | 3자리 숫자 | 수취 은행 기관 코드 | 금융기관 코드 목록 내 값 |
| 수취 계좌번호 | receiveAcctNo | String | Y | 최대 20자리 | 수취 계좌번호 | 숫자만 입력, 예금주 조회 필수 |
| 수취인 성명 | receiveOwnerName | String | Y | 최대 20자 | 예금주 조회 결과 자동 입력 | 읽기 전용 |
| 이체 금액 | transferAmount | Number | Y | 최대 13자리 | 예약 이체 금액 (원 단위) | 1원 이상, 1회 이체 한도 이하 (실행일 잔액은 실행 시점에 검증) |

## [IB-TR-003] 자동이체 등록

### 업무 설명

고객이 설정한 주기(매월, 매주 등)에 따라 반복적으로 이체가 실행되도록 등록하는 화면입니다.
공과금 납부, 정기 송금 등의 용도로 활용되며, 출금일 기준으로 자동 이체가 처리됩니다.
등록 시 유효기간(시작일/종료일)을 설정할 수 있으며, 잔액 부족 시 이체 실패 처리 후 알림이 발송됩니다.

### 화면 구성 요소

- **출금 계좌 선택 영역**
- **수취 계좌 입력 영역**
- **이체 금액 입력 영역**
- **이체 주기 설정 영역** : 주기 선택 (매월/매주/매일), 출금일 선택
- **유효기간 설정 영역** : 시작일, 종료일 (또는 횟수)
- **이체 실패 시 처리 방법 선택** : 당일 재시도 / 익영업일 재시도 / 실패 처리
- **받는 분께 전할 말 입력 영역**
- **자동이체 등록 정보 요약 영역**
- **보안 인증 영역**
- **등록 버튼** 및 **취소 버튼**

### 필드 정보

## [IB-TR-004] 자동이체 조회/해지

### 업무 설명

고객이 등록한 자동이체 목록을 조회하고, 특정 자동이체를 해지하는 화면입니다.
등록된 자동이체의 이체 정보, 주기, 다음 예정 실행일, 누적 이체 횟수 등을 확인할 수 있습니다.
해지 시 보안 인증이 필요하며, 이미 실행 예정인 건은 당일 해지가 제한될 수 있습니다.

### 화면 구성 요소

- **검색 조건 영역** : 출금 계좌 선택, 등록일 기간 조회
- **자동이체 목록 테이블** : 등록 번호, 수취 계좌, 이체 금액, 주기, 다음 실행일, 상태
- **자동이체 상세 팝업/영역** : 선택한 항목의 전체 등록 정보 표시
- **해지 버튼** (목록 행별 또는 상세 화면 내)
- **해지 확인 팝업** : 해지 대상 정보 표시 및 최종 확인
- **보안 인증 영역** (해지 시)
- **페이지네이션**

### 필드 정보

| 필드명 | 필드 ID | 타입 | 필수 | 길이/형식 | 설명 | 유효성 검사 |
|---|---|---|---|---|---|---|
| 조회 출금 계좌번호 | searchAcctNo | String | N | 최대 20자리 | 검색 조건 - 출금 계좌번호 | 미입력 시 전체 계좌 조회 |
| 조회 시작일 | searchFromDate | Date | N | YYYYMMDD | 등록일 기준 검색 시작일 | 종료일 이전 |
| 조회 종료일 | searchToDate | Date | N | YYYYMMDD | 등록일 기준 검색 종료일 | 시작일 이후 |
| 자동이체 등록 번호 | autoTransferNo | String | Y (해지 시) | 자동 발급 | 해지할 자동이체의 등록 번호 | 본인 등록 건 여부 확인 |
| 해지 사유 코드 | cancelReasonCode | String | N | 2자리 | 01:단순 해지, 02:계좌 변경, 03:기타 | 코드 목록 내 값 |
| 인증 수단 코드 | authMethodCode | String | Y (해지 시) | 2자리 | 보안 인증 수단 | 코드 목록 내 값 |
| 인증 값 | authValue | String | Y (해지 시) | - | OTP번호 또는 인증 PIN | 마스킹 처리 |
| 다음 실행 예정일 | nextScheduleDate | Date | - | YYYYMMDD | 시스템 계산 표시 | 읽기 전용 |
| 누적 이체 횟수 | totalExecuteCount | Number | - | 표시용 | 지금까지 성공한 이체 횟수 | 읽기 전용 |
| 상태 코드 | statusCode | String | - | 2자리 | 01:활성, 02:일시정지, 03:해지, 04:만료 | 읽기 전용 |

## [IB-TR-005] 이체 결과 조회

### 업무 설명

고객이 실행한 이체 거래 내역(일반이체, 예약이체 실행 건, 자동이체 실행 건 포함)의 결과를 조회하는 화면입니다.
기간별, 계좌별로 검색할 수 있으며, 이체 성공/실패/처리 중 상태를 확인할 수 있습니다.

### 업무 설명

예치 금액, 가입 기간, 만기 처리 방법(자동 해지/자동 재예치), 이자 지급 방법(만기 일시 지급/월 이자 지급)을 설정합니다.
가입 신청 완료 후 정기예금 계좌번호가 발급되며, 출금 계좌에서 예치금이 즉시 출금됩니다.
